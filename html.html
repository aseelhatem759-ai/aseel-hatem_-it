تعريف لغة HTML

HTML هي اختصار للعبارة الإنجليزية HyperText Markup Language، وتعني لغة ترميز النص التشعبي.

تُستخدم HTML في إنشاء الهيكل الأساسي لصفحات الويب وتنظيم محتوياتها، مثل العناوين والفقرات والصور والروابط والجداول والنماذج.

HTML ليست لغة برمجة، بل هي لغة ترميز تعتمد على مجموعة من الوسوم التي تحدد نوع كل عنصر ومكانه داخل صفحة الويب.

نبذة تاريخية عن HTML

ظهرت لغة HTML في بداية شبكة الويب العالمية، واستُخدمت لتبادل المستندات والمعلومات من خلال صفحات مترابطة تحتوي على نصوص وروابط.

تطورت اللغة عبر عدة إصدارات، ويُعد HTML5 الإصدار الحديث الذي يدعم عناصر متنوعة مثل الصوت والفيديو والعناصر الدلالية والنماذج المتقدمة.

وظيفة لغة HTML

  • إنشاء هيكل صفحات الويب.
  • تنظيم النصوص داخل عناوين وفقرات.
  • إضافة الصور والروابط والقوائم.
  • إنشاء الجداول والنماذج.
  • إضافة ملفات الصوت والفيديو.
  • تحديد معنى أجزاء الصفحة باستخدام العناصر الدلالية.

الهيكل الأساسي لصفحة HTML

تتكون صفحة HTML من عناصر رئيسية، ويُكتب كل عنصر عادةً باستخدام وسم بداية ووسم نهاية، باستثناء بعض العناصر التي لا تحتاج إلى وسم نهاية. 

<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
    <meta charset="UTF-8">
    <title>عنوان الصفحة</title>
</head>
<body>
    <h1>عنوان رئيسي</h1>
    <p>هذه فقرة داخل الصفحة.</p>
</body>
</html>

شرح مكونات الهيكل

العنصر وظيفته
<!DOCTYPE html> يحدد أن المستند يستخدم HTML5.
<html> العنصر الأساسي الذي يحتوي على جميع عناصر الصفحة.
<head> يحتوي على المعلومات الخاصة بالصفحة التي لا تظهر غالبًا داخل المحتوى.
<meta charset="UTF-8"> يساعد على عرض اللغة العربية والرموز بشكل صحيح.
<title> يحدد العنوان الذي يظهر في تبويب المتصفح.
<body> يحتوي على جميع المحتويات الظاهرة للمستخدم.

أهم وسوم HTML

الوسم الاستخدام مثال
<h1> إلى <h6> إنشاء العناوين <h1>عنوان رئيسي</h1>
<p> إنشاء فقرة نصية <p>نص الفقرة</p>
<br> إضافة سطر جديد نص أول<br>نص ثانٍ
<strong> إظهار نص مهم <strong>نص مهم</strong>
<a> إنشاء رابط <a href="page.html">اضغط هنا</a>
<img> إضافة صورة <img src="image.jpg" alt="وصف الصورة">
<ul> و <li> إنشاء قائمة غير مرتبة <ul><li>عنصر</li></ul>
<ol> و <li> إنشاء قائمة مرتبة <ol><li>العنصر الأول</li></ol>
<table> إنشاء جدول <table>...</table>
<form> إنشاء نموذج لإدخال البيانات <form>...</form>

خصائص وسوم HTML

الخصائص أو Attributes هي معلومات إضافية تُكتب داخل وسم البداية، وتساعد على تحديد سلوك العنصر أو معلوماته.

أمثلة على الخصائص

الخاصية تستخدم مع وظيفتها
href <a> تحدد عنوان الرابط.
src <img> و <video> تحدد مكان الملف أو الصورة.
alt <img> تقدم وصفًا للصورة.
id معظم العناصر تمنح العنصر معرفًا خاصًا.
class معظم العناصر تحدد مجموعة أو تصنيفًا للعناصر.
title معظم العناصر تضيف معلومة تظهر عند تمرير المؤشر على العنصر.

مثال على استخدام الخصائص

<a href="https://example.com" target="_blank">
    زيارة الموقع
</a>

<img src="photo.jpg" alt="صورة توضيحية" width="300">

العناصر الدلالية في HTML5

العناصر الدلالية توضّح معنى محتوى الصفحة، وتجعل الكود أكثر تنظيمًا وسهولة في القراءة والفهم.

  • <header>: رأس الصفحة أو القسم.
  • <nav>: قائمة التنقل والروابط الرئيسية.
  • <main>: المحتوى الرئيسي للصفحة.
  • <section>: قسم مستقل داخل الصفحة.
  • <article>: محتوى مستقل مثل مقال أو خبر.
  • <aside>: محتوى جانبي مرتبط بالمحتوى الرئيسي.
  • <footer>: تذييل الصفحة.

مميزات لغة HTML

  1. سهلة التعلم والاستخدام.
  2. مفتوحة ومجانية.
  3. تعمل على مختلف أنظمة التشغيل والمتصفحات.
  4. تدعم اللغة العربية والعديد من اللغات.
  5. تسمح بإضافة النصوص والصور والفيديو والنماذج.
  6. تتوافق مع CSS وJavaScript لتطوير صفحات متقدمة.
  7. تُعد الأساس الذي تُبنى عليه معظم صفحات الويب.

ملاحظات مهمة

  • يجب حفظ ملف HTML بالامتداد .html.
  • يُفضل كتابة الوسوم بحروف صغيرة للمحافظة على تنظيم الكود.
  • يجب إغلاق معظم الوسوم بعد الانتهاء من محتواها.
  • خاصية alt مهمة لوصف الصور عند عدم ظهورها.
  • يمكن فتح ملف HTML مباشرة باستخدام أي متصفح إنترنت.
